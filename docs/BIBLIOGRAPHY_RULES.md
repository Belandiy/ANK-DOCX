# Нормативные правила цитирования и библиографических ссылок

В данном документе зафиксированы результаты аудита и нормативные требования СТО 04–2017 (ЮУрГУ), СТО 17–2008 / СТО 19–2008 / СТО 21–2008, ГОСТ Р 7.0.100–2018 и ГОСТ Р 7.0.5–2008 к цитатам и списку литературы в расширении `academic-docx`.

## 1. Архитектура и три уровня библиографических конструкций

В конвейере `academic-docx` используются Quarto / Pandoc Citeproc, файл библиографии `references.bib` и числовой стиль ГОСТ CSL. Отдельный менеджер источников Word (`CITATION`/`BIBLIOGRAPHY`) сознательно не используется.

Необходимо четко различать три уровня:
1. **Библиографическую ссылку** в тексте (`[1]`, `[1, с. 16]`, `[1, 2]`);
2. **Дословную цитату** с кавычками, сокращениями, пропусками и указанием конкретной страницы;
3. **Запись в списке литературы** (описание книги, статьи, интернет-ресурса).

## 2. Нормативные требования к дословным цитатам и деление ответственности

### Нормативные правила (СТО 04/17/19/21)
- **Кавычки**: Дословная цитата оформляется внешними кавычками-«елочками» (`«...»`).
- **Вложенные цитаты**: Если внутри цитируемого фрагмента есть слова в кавычках или название работы, используются внутренние кавычки-„лапки“ (`«Текст цитаты „вложенная фраза“ продолжается»`).
- **Пропуски и сокращения**: Пропуск отдельных слов обозначается многоточием (`...`), пропуск целых предложений — многоточием в квадратных скобках (`[...]`). Пропуск не должен искажать смысл цитируемого автора.
- **Указание страницы**: Дословная цитата обязательно сопровождается ссылкой на конкретную страницу или диапазон страниц источника: `[@knuth1984, с. 16]` $\rightarrow$ `[1, с. 16]`, `[@knuth1984, с. 16–20]` $\rightarrow$ `[1, с. 16–20]`.
- **Повторная ссылка**: При повторном цитировании того же источника используется стандартный ключ: `[@knuth1984]` $\rightarrow$ `[1]`, с локатором страницы при необходимости: `[@knuth1984, с. 100]` $\rightarrow$ `[1, с. 100]`.
- **Группа источников**: Несколько источников через точку с запятой `[@knuth1984; @gost2008]` сводятся в единые скобки: `[1, 2]`.
- **Цитирование по вторичному источнику**: Если источник недоступен и цитируется по другой работе, перед ссылкой пишется фраза «Цит. по:»: *«Текст цитаты» (Цит. по: [1, с. 16])*.

### Деление ответственности

| Элемент | Зона ответственности | Кто проверяет |
|---|---|---|
| Точность дословного текста | Автор | Автор / Научный руководитель |
| Типографика кавычек (`«... „...“ ...`) | Автор | Автор |
| Оформление пропуска (`...`, `[...]`) | Автор | Автор |
| Формулировка «Цит. по:» | Автор | Автор |
| Наличие ключей источника в `.bib` | Программная / Расширение | Quarto / Pandoc / C# `DocxInspection` |
| Оформление префиксов локатора (`с.`, `pp.`) | Программная / Расширение | Pandoc Citeproc / CSL |
| Проверка отсутствия неиспользуемых источников (СТО 04) | Программная / Расширение | C# `DocxInspection.ReadCitations()` |

## 3. Нормативное описание записей в списке литературы

Поддерживаются базовые нормативные типы BibTeX, преобразуемые CSL ГОСТ:

### Книга (`@book`)
```bibtex
@book{knuth1984book,
  author    = {Кнут, Д. Э.},
  title     = {Искусство программирования},
  publisher = {Вильямс},
  address   = {М.},
  year      = {2000},
  numpages  = {720}
}
```
*Результат в списке*: Кнут, Д. Э. Искусство программирования / Д. Э. Кнут. – М. : Вильямс, 2000. – 720 с.

### Статья в журнале (`@article`)
```bibtex
@article{knuth1984,
  author  = {Knuth, Donald E.},
  title   = {Literate Programming},
  journal = {The Computer Journal},
  year    = {1984},
  volume  = {27},
  number  = {2},
  pages   = {97--111}
}
```
*Результат в списке*: Knuth, Donald E. Literate Programming // The Computer Journal. – 1984. – Vol. 27, № 2. – P. 97–111.

### Электронный ресурс / веб-страница (`@online` / `@webpage` / `@misc`)
```bibtex
@online{gost2018,
  title   = {ГОСТ Р 7.0.100-2018. Библиографическая запись. Библиографическое описание},
  url     = {https://allgosts.ru/01/140/gost_r_7.0.100-2018},
  urldate = {2026-10-29}
}
```
*Результат в списке*: ГОСТ Р 7.0.100-2018. Библиографическая запись. Библиографическое описание. – URL: https://allgosts.ru/01/140/gost_r_7.0.100-2018 (дата обращения: 29.10.2026).

## 4. Сортировка иностранных источников и нумерация

По СТО 04/19/21 допускается два варианта порядка списка литературы:
1. **Алфавитно-языковая группировка**: Сначала отечественные источники на кириллице (в алфавитном порядке А–Я), затем иностранные источники на латинице (в алфавитном порядке A–Z).
2. **Порядок первого упоминания**: Источники нумеруются строго по порядку их появления в тексте.

В числовом стиле CSL ГОСТ с включенной алфавитно-языковой сортировкой текстовые ссылки `[1]`, `[2]` получают номера, строго соответствующие отсортированным позициям источников в финальном списке литературы. Порядок ссылок в тексте согласован со списком автоматически.

---

## 5. Запрет неиспользуемых источников (СТО 04)

Согласно СТО 04–2017, в список литературы **запрещено** включать источники, на которые нет ни одной ссылки в основном тексте работы.
- Использование `nocite: '@*'` в YAML запрещено для профилей СТО 04.
- В модуле `AcademicDocx.Core` (метод `DocxInspection.ReadCitations()`) реализована автоматическая проверка: если в файле присутствуют записи источников, не имеющие гиперссылок/упоминаний `ref-key` в тексте, фиксируется поле `UncitedSources`.
