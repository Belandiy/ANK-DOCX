# Документация проекта

Действующий формат — `academic-docx`: Quarto Book, knitr, R и flextable. Установка и сборка описаны в [основном README](../README.md), авторский интерфейс — в [инструкции агенту](../academic/AGENT_GUIDE.md).

Графики строим преимущественно ggplot2 с экспортом SVG через svglite. TikZ, PGFPlots и quarto_tikz исключены из рабочего стека; соответствующий отчёт ниже сохранён как история завершённого исследования.

## Разработка

- [Архитектура служебного слоя](SERVICE_LAYER_ARCHITECTURE.md) — C# для собственной обработки DOCX и Word, границы Quarto/R/Lua; рабочая сборка переключена, собственные Python/PS1 удалены.
- [Приёмка перехода на C#](research/SERVICE_LAYER_MIGRATION.md) — команды, проверки, сборки двух профилей, PDF и оставшиеся ограничения.
- [План разработки](DEVELOPMENT_PLAN.md) — этапы и критерии; статус реализации сверяйте с README действующего расширения.
- [Вопросы продукта](PRODUCT_QUESTIONNAIRE.md) — требования и пока не принятые решения.
- [Общий reference-docx ЮУрГУ](REFERENCE_DOCX.md) — стили основной части, основания в СТО, различия параметров и проверка в Word.
- [Математика в QMD](MATH_RULES.md) — обозначения, расчётные формулы, новые и ранее определённые символы.
- [Ссылки и сноски](REFERENCE_MODEL.md) — пять базовых назначений, стандартный синтаксис и проверка готовых механизмов Quarto/Word.
- [Цитаты и библиография](BIBLIOGRAPHY_RULES.md) — нормативные правила СТО 04/17/19/21, аудиторский статус дословных цитат, типов записей и сортировки.
- [Таблицы](TABLE_RULES.md) — ширина по области текста, повторяемая шапка, программное разделение по страницам Word и границы поддержки продолжения/окончания.
