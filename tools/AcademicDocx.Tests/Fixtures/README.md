# Контрольные входы миграции

- `pagination.docx` — неизменённый вход `build/table-split-qa/three-input.docx` завершённого опыта: 90 строк данных и одна повторяемая строка шапки. Меньшие варианты создаются SDK внутри теста. Это фиксированный тестовый корпус, не зависимость рабочей сборки от build/.
- `book-before-word.docx` — неизменённый промежуточный `academic/.quarto/coursework-tables-ready.docx.before-word.docx`: две строки объединённой шапки, 55 формул в длинной таблице и итог. Вход до нормализации Word содержит известные ошибки схемы; итог должен быть корректен.
- `reference-legacy.docx` — результат последнего запуска прежнего Python-редактора на текущем reference-docx перед его удалением. Тест сравнивает XML документа, стилей, нумерации и колонтитулов с результатом SDK, учитывая эквивалентные записи boolean и пространства имён. Python для теста не нужен.

Файлы сохранены 29 октября 2026 года. Научное содержимое является демонстрационным. Числа объектов в этих фикстурах не объявляются универсальным контрактом документа.
